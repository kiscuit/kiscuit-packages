手動インストール

.tgzをダウンロードし、Unity Package Managerで「Add package from tarball」を選びます。

.tgzをダウンロード

VCC / ALCOM のインストール手順

  1. ① ボタンを押してアプリを開く
  2. ② 「Kiscuit Packages」を追加する
  3. ③ 対象プロジェクトで「Kiscuit Hair Tool」をインストール

※ ALCOMとVCCは同じ vcc: リンクを使います。開くアプリはPCのプロトコル設定で決まり、Unityプロジェクトへのインストールは別途確認が必要です。

ボタンが動かない場合

VCCの Settings → Packages → Add Repository、またはALCOMの Repositories → Add Repository に以下のURLを貼り付けてください。

https://raw.githubusercontent.com/kiscuit/kiscuit-packages/main/index.json

依存パッケージ

VRChat SDK - Avatars、Modular Avatar / NDMF、lilToon が必要です。リポジトリが未登録の場合は先に追加してください。
